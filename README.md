# Catalina Foodie's House

DFK20013 Web Design Technology: Problem Based Assignment (Theme: Foodies).

A simple food website made with HTML, CSS, Bootstrap 5, jQuery and basic JavaScript.

## How to run

Open `index.html` in a web browser. No internet or server needed
(Bootstrap and jQuery are saved in `css/vendor` and `js/vendor`).

## Pages

- `index.html`: Home
- `menu.html`: Menu with Order buttons and order total
- `contact.html`: Contact form with validation

See `docs/presentation-notes.md` for how each assignment task is done.
